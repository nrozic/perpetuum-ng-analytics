## Design skills (required)

Work that touches UI, UX, interface copy or documents (PDF, letterhead, e-mail) starts by loading the skills `ui-designer`, `ux-designer`, `behavioral-design` and `trilium-pozitivna-komunikacija`, which are then applied throughout. The report and the PR description state that they were used. Whoever delegates such work to another agent says so in the instructions. Work done without them is not finished.
